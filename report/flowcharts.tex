To get a clear view of how the code works, we will use flowcharts of the classes , but first we will explain the way the files are organized:
\begin{itemize}
	\item \textbf{particle.py} \\
	contains the Particle parent class and the Uranium and Neutron subclasses.
	\item \textbf{shapes.py} \\
	contains the implementation of the Simulator parent class with the beam (BeamSim) and sphere (SphereSim) subclasses. It also contains an unused Point class.
	\item \textbf{test.py} \\
	contains the script with the explanation and implementation of the code for the tasks\supcite{opgave}.
	\item \textbf{randomizer.py} \\
	testing file for the randomizer implemented in the Neutron and SphereSim classes.
	\item \textbf{color\_picker.md} \\
	markdown file containing the hexcodes with the colors used in visual simulations.
\end{itemize}
All these files, along with the files of this report are available through the GitHub repository: \url{https://gitfront.io/r/Destruckting/vQDpr4HM43Ue/examentaak/}

The flowcharts are split into three, one for the Simulator parent class, as the SphereSim and BeamSim subclasses don't change the working, and one for both the Uranium and Neutron class, as the Particle parent class only adds property protection and string representation.
